3. ROL DE HTML, CSS Y JAVASCRIPT EN RUEDA LIBRE
   HTML: estructura y contenido. Ejemplo: <h1>Rueda Libre</h1> es el título del sitio.
   CSS: presentación. Ejemplo: h1 { color: green; } para pintar el título de verde.
   JavaScript: comportamiento. Ejemplo: mostrar un mensaje al hacer clic en "Reservar ahora".
